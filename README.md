# 🚀 Android Emulator RapidOCR Ticket Automation

안드로이드 에뮬레이터(LDPlayer) 환경에서 OCR(문자 인식)을 활용하여 티켓 예매 과정을 자동화하는 초고속 파이썬 스크립트입니다.

## 📌 주요 특징
* **가벼운 연산:** RapidOCR(ONNX Runtime)을 사용하여 CPU 부하를 최소화하고 응답 속도를 극대화했습니다.
* **한글 특화 인식:** `korean_PP-OCRv3_rec_infer.onnx` 모델을 적용하여 한국어 버튼("간편예매", "바로예매" 등)을 정확하게 인식합니다.
* **3단계 루프 자동화:** [1단계: 간편예매] ➔ [2단계: 바로예매] ➔ [3단계: Confirm/확인 또는 결제할티켓(성공)] 구조로 동작합니다.
* **화면 상태 자동 감지:** 현재 단계보다 앞선 화면이 보이면 OCR 결과를 기준으로 3단계 ➔ 2단계 ➔ 1단계 순서로 상태를 보정합니다.
* **스마트 타임아웃:** 5초마다 현재 단계를 재시도하며, 3단계는 Confirm/확인 버튼을 최대 10회 탐색한 뒤 1단계로 초기화합니다.
* **휴대폰 호환 보완:** 작은 버튼은 확대 OCR로 재검사하고, OCR 결과 주변의 파란색 확인 버튼을 마지막 보완 수단으로 검사합니다.
* **텔레그램 알림:** 시작·성공 알림을 보내며, 설정 시 30분마다 실행 상태 하트비트를 전송합니다.
* **화면 꺼짐 방지:** 실행 중 ADB로 화면 켜짐을 유지하고, 성공 또는 종료 시 설정을 해제합니다.
* **최적화된 인터벌:** 0.5초 간격의 스캔 주기 적용으로 게임 및 PC 부하를 최소화했습니다.

## 🛠️ 사전 요구사항 (Prerequisites)

### 1. LDPlayer 설정
1. **LDPlayer 다운로드 및 설치**
   * [LDPlayer 공식 홈페이지](https://www.ldplayer.net/)에서 에뮬레이터를 다운로드하여 설치합니다.
2. **ADB 디버깅 설정 (로컬 디버깅 활성화)**
   * LDPlayer 우측 상단의 **[설정(톱니바퀴)] ➔ [기타 설정(또는 모델 설정)]** 등으로 이동합니다.
   * **[ADB 디버깅]** 항목을 **[로컬 디버깅(Local Debugging)]**으로 선택하여 켜줍니다.
3. **ADB 연결 확인**
   * LDPlayer가 실행 중이고 ADB 디버깅이 켜져 있으면 스크립트가 연결된 기기를 자동으로 선택합니다.

### 2. 실제 휴대폰 설정
1. **개발자 옵션 활성화**
   * 휴대폰 설정에서 개발자 옵션을 활성화합니다.
2. **USB 디버깅 활성화**
   * 개발자 옵션에서 **USB 디버깅**을 켭니다.
3. **PC 연결 및 권한 허용**
   * USB 케이블로 휴대폰을 연결하고, 휴대폰에 표시되는 USB 디버깅 허용 메시지를 승인합니다.
4. **ADB 연결 확인**
   * `adb devices` 명령에서 기기 상태가 `device`로 표시되어야 합니다.
   * 실행 중 화면 꺼짐 방지를 위해 ADB 연결이 유지되어야 합니다.

### 3. 텔레그램 봇 토큰 및 Chat ID 설정
   ### 1단계: 텔레그램 봇 생성하기 (BotFather 이용)
   1. 텔레그램 앱을 켜고 검색창에 **`@BotFather`** (공식 봇 관리자)를 검색하여 대화방을 엽니다.
   2. 하단의 **[시작하기]** 버튼을 누르거나 채팅창에 `/newbot`을 입력합니다.
   3. 봇의 **이름(Display Name)**을 입력합니다. (예: `티켓팅 알림봇`)
   4. 봇의 **아이디(Username)**를 입력합니다. (반드시 영문으로 작성해야 하며, 끝에 반드시 **`bot`** 또는 **`_bot`**으로 끝나야 합니다. 예: `my_ticket_helper_bot`)
   5. 생성이 완료되면 긴 영어로 된 **API 토큰(HTTP API Token)**이 발급됩니다. 이 토큰을 복사해 둡니다.

   ### 2단계: 챗 ID (Chat ID) 확인하기
   1. 텔레그램 검색창에 **`@userinfobot`** 또는 **`@getmyid_bot`**을 검색합니다.
   2. 대화방에 들어가 `/start`를 입력합니다.
   3. 봇이 답장으로 보내주는 숫자들 중 **`Id`** (예: `123456789`)에 해당하는 숫자가 본인의 챗 ID입니다. 이 번호를 복사해 둡니다.

   ### 3단계: 코드에 적용하기
   발급받은 토큰과 챗 ID를 [KTX_Macro_by_RapidOCR.py](KTX_Macro_by_RapidOCR.py) 상단의 `[사용자 설정]` 구역에 입력합니다.
   ```python
   TELEGRAM_TOKEN = "여기에_봇_토큰_입력"  # 예: "123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ"
   CHAT_ID = "여기에_챗_아이디_입력"         # 예: "123456789"
   ```
   토큰이나 Chat ID를 비워 두면 텔레그램 전송 없이 매크로만 실행됩니다.

### 4. Python 환경 및 필수 패키지 설치
1. Python (3.8 이상 권장) 설치
2. 터미널에 아래 명령어 입력하여 필수 패키지 설치
   ```bash
   pip install rapidocr_onnxruntime opencv-python numpy requests
   ```

### 5. 실행방법
1. 코레일톡(또는 예매 앱)에서 **간편예약 기능을 미리 설정**합니다.
   * 앱에 등록된 간편예약 목록 중 **가장 첫 번째 항목**이 매크로의 예매 대상입니다.
   * 원하는 승차권 조건을 첫 번째 간편예약 항목으로 배치해야 합니다.
2. LDPlayer 또는 휴대폰에 KTX 앱을 켜둔 상태에서 실행합니다.
   ```bash
   python KTX_Macro_by_RapidOCR.py
   ```
